## Current state
Organic Maps OÜ is an Estonian private limited company, registry code 16225385, registered for software publishing. [[2026-11-03-estonian-register-organic-maps-ou#c1]] [[2026-11-03-estonian-register-organic-maps-ou#c8]] Viktar Havaka has been its sole shareholder since 2025-08-28, and its board is Havaka and Alexander Borsuk. [[2026-11-03-estonian-register-organic-maps-ou#c3]] [[2026-11-03-estonian-register-organic-maps-ou#c4]] It reported 0 employees for the third quarter of 2026. [[2026-11-03-estonian-register-organic-maps-ou#c7]] It says installs passed 12 million, and since 2025 part of the contributor base has run a fork called CoMaps. [[2026-11-03-organic-maps-12m-installs#c1]] [[2026-11-03-lwn-comaps-organic-maps-fork#c6]]
