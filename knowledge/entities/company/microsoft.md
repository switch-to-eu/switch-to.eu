## Current state
Microsoft has been a DMA gatekeeper since 2023-09-05, but the Commission decided in 2024 that Bing, Edge and Microsoft Advertising are not gatekeeper services. [[2026-11-03-ec-bing-edge-not-gatekeepers#c1]] [[2026-11-03-ec-bing-edge-not-gatekeepers#c3]] Windows is subject to the DMA rule on changing defaults. The Commission says Microsoft complied by making more apps uninstallable and pinning the default browser to the taskbar, and does not mention a search choice screen. [[2026-11-03-ec-dma-review-2026-choice-screens#c2]] [[2026-11-03-ec-dma-review-2026-choice-screens#c4]] In the EEA, apps can supply web results in Windows Search. [[2026-11-03-windows-dma-updates-2025#c1]] A report by the campaign group Ekō says Microsoft hosts key components of an Israeli permit app for Palestinians in Irish data centres. [[2026-11-03-euobserver-microsoft-ireland-israeli-app#c2]]

## Facts
- 2026-11-03 · A report by the campaign group Ekō says Microsoft hosts key components of Al Munasseq, the app Israel's COGAT unit uses to manage Palestinians' movement, in data centres in Ireland. An Irish MP called for an investigation. [[2026-11-03-euobserver-microsoft-ireland-israeli-app#c1]] [[2026-11-03-euobserver-microsoft-ireland-israeli-app#c2]] [[2026-11-03-euobserver-microsoft-ireland-israeli-app#c4]]
- 2026-04-28 · The Commission's DMA review lists Windows under Article 6(3), and says Microsoft complied by making more apps uninstallable and pinning the default browser to the taskbar. It does not mention a Microsoft search choice screen. [[2026-11-03-ec-dma-review-2026-choice-screens#c2]] [[2026-11-03-ec-dma-review-2026-choice-screens#c4]]
- 2025-07-01 · From July 2025 (the source gives the month only), Windows changes for the DMA reached retail PCs in the EEA: "Set default" for a browser sets more link and file types and pins the browser to the taskbar unless the user unticks it. [[2026-11-03-windows-dma-updates-2025#c4]]
- 2025-06-02 · Its post on Windows changes for the DMA says apps in the EEA can provide web search results in Windows Search, enabled automatically when the app is installed. The post describes no search engine choice screen. [[2026-11-03-windows-dma-updates-2025#c1]] [[2026-11-03-windows-dma-updates-2025#c5]]
- 2024-02-12 · The Commission decided that Bing, Edge and Microsoft Advertising should not be designated as gatekeeper services under the DMA. [[2026-11-03-ec-bing-edge-not-gatekeepers#c1]]
- 2023-09-05 · Designated a gatekeeper under the DMA from this date, per the Commission. [[2026-11-03-ec-bing-edge-not-gatekeepers#c3]]
