**Summary:** The official FAQ entry on wrong or missing places in [[services/organic-maps]], which uses OpenStreetMap data. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Organic Maps uses OpenStreetMap as its map data source.
- `c2` Users can leave a note for OpenStreetMap volunteers or register and edit the map themselves.
- `c3` With an OpenStreetMap account, users can add places and edit addresses, opening hours and names inside Organic Maps, and the edits upload to OpenStreetMap.
- `c4` The project aims to update the maps in the app one to four times a month, so OpenStreetMap edits appear in a later map update.
