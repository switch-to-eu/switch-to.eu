**Summary:** Vivaldi's help page on saved passwords in [[services/vivaldi]] for Android. It describes saving, viewing, deleting and exporting passwords and using another autofill service. It lists no option to import a password file on Android. First published 2019-09-09, no last-updated date shown; read on 2026-11-03.

**Claims**
- `c1` Saved passwords on Android are managed in Vivaldi menu > Settings > Password Manager. Viewing a password requires the device's screen lock.
- `c2` Passwords can be exported to a CSV file via Password Manager > 3-dot menu > Export passwords. Vivaldi warns the file is readable by any app with access to its folder.
- `c3` Saved passwords cannot be edited in Settings. They are updated by logging in with the new password and accepting the update prompt.
- `c4` Vivaldi on Android can hand autofill to a third-party password manager via Settings > Autofill services > Autofill using another service.
- `c5` All saved passwords are deleted via Settings > Privacy > Clear browsing data > Advanced, with All time and Saved passwords selected.
