**Summary:** Qwant's overview page for setting [[services/qwant]] as the search engine on desktop browsers, with links to per-browser articles. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Qwant offers two methods: its browser extension, which it recommends, or changing the browser settings by hand.
- `c2` Qwant says the extension sets Qwant as both the default search engine and the new-tab home page, and can be disabled at any time; manual settings change only the search engine.
- `c3` Qwant lists extension and manual guides for Chrome, Firefox and Brave, and a Safari (Mac) guide.
- `c4` On Edge, Qwant's route is its extension from Microsoft Edge Add-ons (Get > Add extension).
- `c5` On Opera, Qwant says to add it under Manage search engines with keyword `q` and URL `https://www.qwant.com/?q=%s`, then choose Make default.
- `c6` On iOS and Android, Qwant points to its own mobile app, which it says lets users use Qwant as their default search engine.
