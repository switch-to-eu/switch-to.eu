**Summary:** Proton's help article on Easy Switch, the import assistant built into [[services/proton-mail]]. For Google it imports emails, contacts and calendars. Files from [[services/google-drive]] are not among the data types it names. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Easy Switch is built into Proton Mail and is launched from Settings → All settings → Import via Easy Switch.
- `c2` For a Google account, the user selects which data to import: emails, contacts or calendars.
- `c3` The article describes Easy Switch as transferring data to Proton Mail and Proton Calendar.
- `c4` Easy Switch can run imports from up to two email accounts at the same time, but only one import at a time from the same account.
- `c5` For Yahoo, Outlook and other IMAP imports, Proton says it deletes the login details once the import is complete.
