**Summary:** Vivaldi's own comparison page between [[services/vivaldi]] and [[services/chrome]]. It is marketing: rated medium, and its statements about Chrome are Vivaldi's view. Useful for what Vivaldi confirms about its own product, including the absence of AI features. The page says "Last updated: October 2026" with no day, so the first of the month is used; read on 2026-11-03.

**Claims**
- `c1` Vivaldi says it is employee-owned, has no external investors and is based in Europe.
- `c2` Vivaldi says it has no generative AI features: no summarising tools and no chatbots.
- `c3` Asked whether Vivaldi has Gemini or AI features like Chrome, Vivaldi answers no, and says Chrome has Gemini built in as a core feature.
- `c4` Vivaldi says Chrome extensions from the Chrome Web Store work in Vivaldi because both are built on Chromium.
- `c5` Vivaldi says its sync requires the user to set their own encryption key, while Chrome's encrypted sync option is off by default.
- `c6` Vivaldi lists built-in mail, calendar, feed reader, notes, screenshot tool, translation, tab tiling, workspaces and two-level tab stacks, which its table marks as missing from Chrome.
- `c7` The table marks installing websites as desktop apps (PWAs), tab groups, custom search engines and reader mode as supported in both browsers.
