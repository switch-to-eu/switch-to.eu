**Summary:** OpenAI's help article on plugins in [[services/chatgpt]], the replacement for custom GPTs. The page says "Updated: 6 days ago" without an exact date, so the fetch date is used.

**Claims**
- `c1` A plugin can include skills, connected apps, app templates and extensions. Some plugins include only skills and do not require an app connection.
- `c2` The plugin directory is available across ChatGPT plans. Installing or using an individual plugin depends on plan, workspace, role, region and the plugin's capabilities.
- `c3` ChatGPT automatically uses installed plugins when they are relevant to a request. Users can also select a plugin with an @ mention.
- `c4` The directory has Public, Your workspace, Personal and Installed views. Personal shows plugins the user created or that others shared with them.
