**Summary:** Google's help article on installing and using Drive for desktop, the Windows and macOS sync app for [[services/google-drive]]. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Drive for desktop is offered for Windows and macOS.
- `c2` In the Google Drive folder in File Explorer or Finder, files in Google Docs, Sheets and Slides open in the web browser when double-clicked, while other files open in their desktop apps.
- `c3` Streaming a file uses almost no space on the computer, while mirroring downloads a full copy.
- `c4` Shared files never count against the user's Google storage, but can fill the computer's disk if synced.
- `c5` Work or school accounts may not be allowed to use Drive for desktop, or need the organisation to install it.
