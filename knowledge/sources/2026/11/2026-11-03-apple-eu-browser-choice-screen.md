**Summary:** Apple's developer page on the Digital Markets Act browser choice screen in iOS and iPadOS, with the per-country browser lists (stated as current as of November 2025). The page has no single publication date, so the fetch date is used. Browsers from [[services/ecosia]], [[services/qwant]] and [[services/startpage]] appear on some country lists.

**Claims**
- `c1` Apple says iOS and iPadOS include a choice screen for the default web browser to meet DMA requirements in the EU.
- `c2` From iOS 18.2 and iPadOS 18.2, users with Safari as default see the choice screen after installing the update; it is not shown if another browser is already default, and it is shown once per device.
- `c3` When moving to a new device, users whose previous default browser was Safari must choose a default browser again.
- `c4` Up to 11 of the most downloaded eligible browsers in each country are shown in addition to Safari, in a random order per user; Apple updates the list once per calendar year.
- `c5` On the lists current as of November 2025, Ecosia's browser appears for many EU countries, Startpage's browser for some (for example Austria), and Qwant's browser for some (for example Belgium on iOS).
- `c6` The page describes a browser choice screen; it does not describe a search engine choice screen.
