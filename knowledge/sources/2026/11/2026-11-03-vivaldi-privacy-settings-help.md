**Summary:** Vivaldi's help page listing the desktop privacy and security settings in [[services/vivaldi]] and their defaults, including which Google services stay in the browser. First published 2019-06-24 with no last-updated date shown, though it describes Safe Browsing V5, so it has been edited since; read on 2026-11-03.

**Claims**
- `c1` Search suggestions are disabled by default, because everything typed would be sent to the selected search engine.
- `c2` Blocking ads on sites with abusive ad practices is enabled by default.
- `c3` Vivaldi uses Google Safe Browsing in standard mode by default. The enhanced mode, which uploads hashes of all visited URLs, is not enabled, which Vivaldi says is a privacy choice.
- `c4` Through Safe Browsing, Google receives the user's IP address and a Safe Browsing cookie kept in a separate cookie jar.
- `c5` Three bundled Google extensions are on by default: Google Services Token (without it, logging in to Google accounts is not possible), Hangouts (screen sharing in Google Meet) and Web Store (needed to add Chrome Web Store extensions).
- `c6` Browsing history is kept for three months by default. Other options range from session only to forever.
- `c7` Proton VPN is integrated and usable for free with a Vivaldi account, and can be switched off in Privacy and Security settings.
- `c8` A fallback to Google's DNS servers (8.8.8.8 and 8.8.4.4) for navigation errors is enabled by default and can be disabled.
