**Summary:** Mistral's documentation for Memories, the memory feature of the old Le Chat interface of [[services/mistral-le-chat]], now marked legacy. It lists who may have their memories used for training. The page does not describe an import from ChatGPT. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Memories is a legacy Chat feature; the Chat tab is being removed progressively and Knowledge Base is the equivalent.
- `c2` In the legacy Memories tab, users can view, edit (pencil icon) and delete single memories, or clear all.
- `c3` Memories are stored for the duration of the subscription.
- `c4` On Free, Pro and Student plans, prompts that include Memories may be used to train Mistral's models unless the user opts out in account settings.
- `c5` Team and Enterprise plans are opted out of model training by default.
- `c6` Mistral says it does not use Memories data for advertising, ad profiles or data selling.
