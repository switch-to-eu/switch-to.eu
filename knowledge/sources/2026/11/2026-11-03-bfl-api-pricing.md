**Summary:** Black Forest Labs' pricing page for the FLUX API and open-weights licences. Prices are in US dollars. No date on the page, so the fetch date is used.

**Claims**
- `c1` The API is pay as you go, with no subscription or seat fees, charged per generated image by resolution tier.
- `c2` The calculator's default example shows $0.048 per image.
- `c3` Open-weights licences come in Builder (10K images per month), Platform and Professional (100K images per month), Enterprise and Synthetic Data tiers.
- `c4` Failed generations and outputs withheld by moderation are not charged.
