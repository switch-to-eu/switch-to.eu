**Summary:** OpenAI's help article on Memory in [[services/chatgpt]]: what it draws on, where to review it and how to delete it. It does not mention a memory export file. No date was readable on the page, so the fetch date is used.

**Claims**
- `c1` Memory controls are under Settings, Personalization, Memory, and can include saved memories, reference chat history and a memory summary, depending on plan and region.
- `c2` Users can ask ChatGPT what it remembers about them.
- `c3` Saved memories are stored separately from chat history; deleting a chat does not delete a saved memory created from it.
- `c4` OpenAI may retain logs of deleted saved memories for up to 30 days for safety and debugging.
- `c5` Turning off "Reference chat history" schedules information remembered from past chats for deletion within 30 days.
- `c6` For personal accounts, OpenAI may use chats and remembered information to improve models while "Improve the model for everyone" is on.
- `c7` Temporary chats do not create or update memories.
- `c8` Users can edit the memory summary or a saved memory when those controls are available, or tell ChatGPT that remembered information is wrong.
