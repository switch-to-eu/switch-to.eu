**Summary:** Google's help article on importing passwords into and exporting them out of Google Password Manager in [[services/chrome]]. The computer, Android and iPhone/iPad versions of the page were read. The page shows no date, so the fetch date is used.

**Claims**
- `c1` On a computer, passwords are exported via Chrome's More menu > Passwords and autofill > Google Password Manager > Settings > Export passwords > Download file.
- `c2` On Android, passwords are downloaded to a .csv file via More > Settings > Autofill and passwords > Google Password Manager > Settings > Export passwords & passkeys > Download file. A screen lock is required.
- `c3` On Android, passwords and passkeys can also be exported directly into another password manager app that supports importing from Google Password Manager.
- `c4` On iPhone and iPad, export is under More > Settings > Autofill and passwords > Password Manager > Settings > Export data, where the user selects passwords or passkeys and a destination app. A CSV export is also possible.
- `c5` Google Password Manager imports passwords only from .csv files whose first line has url, username and password columns.
- `c6` Google warns that a password .csv file left on a device can be opened by anyone who uses the device, and says to delete it.
