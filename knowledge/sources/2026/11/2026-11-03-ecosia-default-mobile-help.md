**Summary:** Ecosia's mobile guide for using the Ecosia app or setting [[services/ecosia]] as the search engine in Safari (iOS), Chrome, Firefox and Brave on Android. Last updated 2026-01-02 according to the page. Reliability is high for Ecosia's own instructions; for other browsers' menus it is a third party.

**Claims**
- `c1` On iPhone, Ecosia says to open Settings > Safari > Search Engine and select Ecosia.
- `c2` On Android Chrome, the path is the three-dots menu > Settings > Basics > Search Engine > Ecosia.
- `c3` Ecosia says Chrome on Android only shows the top 5 search engines in a country, so Ecosia may not be available; its fallback is setting Ecosia as the home page.
- `c4` On Firefox for Android, Ecosia says to pick Ecosia under Search if available in the region, or add it under "Manage alternative search engines" with the search URL `https://ecosia.org/search?q=%s`.
- `c5` On Brave for Android, the path is the three-dots menu > Settings > General > Search engines > Standard Tab > Ecosia.
- `c6` The Ecosia iOS app can be set as the default browser (needs iOS 15 or later), and so can the Android app.
