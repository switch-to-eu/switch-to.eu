**Summary:** Startpage's steps for making [[services/startpage]] the default search engine in Firefox for iOS. The page shows no date, so the fetch date is used. Reliability is high for Startpage's own instructions; for Firefox's menus it is a third party.

**Claims**
- `c1` In Firefox for iOS, Startpage says to open Settings > Search > Add Search Engine and save the title Startpage.com with the URL `https://www.startpage.com/sp/search?query=%s`.
- `c2` Then tap the current default search engine and select Startpage.
