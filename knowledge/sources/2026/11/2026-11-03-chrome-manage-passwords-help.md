**Summary:** Google's help article on saving, exporting and deleting passwords in Google Password Manager in [[services/chrome]] (computer version read). The page shows no date, so the fetch date is used.

**Claims**
- `c1` When signed in, Chrome can save passwords to the user's Google Account and use them across devices and in some apps. When not signed in, Chrome stores passwords locally on the device.
- `c2` Passwords saved to a Google Account can be managed in any browser at passwords.google.com.
- `c3` To export, open Google Password Manager, select Settings, and choose Download file next to Export Passwords.
- `c4` All Google Password Manager data, including passwords and passkeys, is deleted via Google Password Manager > Settings > Delete all Google Password Manager data > Delete data > Delete.
