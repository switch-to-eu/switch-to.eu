**Summary:** Proton's help article on version history and duplicate uploads in [[services/proton-drive]]. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Uploading a file with the same name and extension as an existing one offers: replace existing file (old one kept as a previous version), keep both, or skip; "Apply to all duplicate files" applies the choice to a whole batch.
- `c2` Version history is opened by right-clicking a file and choosing "See version history"; a version can be restored, downloaded or deleted.
- `c3` Proton Docs and Proton Sheets keep their own version history inside the editor; a past version can be exported as .docx (Docs) or .xlsx (Sheets).
- `c4` On Proton Free, Drive keeps up to 10 versions of each file for up to 7 days, and this cannot be changed.
- `c5` On paid plans, Drive keeps up to 200 versions of each file for up to 10 years, with a configurable retention period.
