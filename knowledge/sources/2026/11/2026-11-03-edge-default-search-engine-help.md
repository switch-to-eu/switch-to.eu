**Summary:** Microsoft's help article on changing the address-bar search engine in [[services/microsoft-edge]] on Windows, which ships with [[services/bing-search]] as default. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Microsoft recommends keeping Bing as default but says Edge can use any site that uses OpenSearch technology as its default search engine.
- `c2` The first step is to perform a search in the address bar with the search engine the user wants as default.
- `c3` The path is Settings and more > Settings > Privacy, search, and services > Search and connected services > Address bar and search, then pick from the "Search engine used in the address bar" menu.
- `c4` To add a search engine that is not listed, search with it once from the address bar; it then appears in the list of options.
- `c5` The article applies to Windows 11, Windows 10 and Windows 8.1.
