**Summary:** The entry page of Mistral's product documentation for Vibe, the renamed [[services/mistral-le-chat]]. It explains that the Chat and Work tabs were merged in September 2026. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Vibe runs in two modes: Work (web and mobile apps, for conversations and multi-step tasks) and Code (terminal, VS Code or remote cloud sessions).
- `c2` Since September 22, 2026, Chat and Work are merged into one experience with a fast/think toggle, and chat.mistral.ai remains the entry point with plan, history and settings preserved.
- `c3` Self-serve Free, Pro and Teams accounts migrate first; Enterprise organisations get a six-month migration window.
- `c4` Users who relied on Agents should use Skills instead, invoked with `@`.
- `c5` Temporary Chat starts a conversation that is not saved to history or used to train Mistral's models; Mistral says it only logs that a Temporary Chat happened.
- `c6` Mobile apps exist for iOS and Android.
