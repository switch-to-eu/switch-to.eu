**Summary:** Proton's help article on the command-line tool for [[services/proton-drive]], built on the Proton Drive SDK. The page shows no date, so the fetch date is used.

**Claims**
- `c1` The Proton Drive CLI runs on macOS, Windows and Linux and is downloaded from the Proton Drive download page.
- `c2` The user signs in with `./proton-drive auth login`, which authenticates through the browser.
- `c3` Files are uploaded with a `filesystem upload` command, for example `./proton-drive filesystem upload ~/Documents/* /my-files/Documents`.
- `c4` The CLI can also list folders, download folders and invite people to shared folders.
- `c5` Proton positions the CLI for automation, backups and scripts, without a desktop application.
