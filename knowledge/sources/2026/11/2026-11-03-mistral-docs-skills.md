**Summary:** Mistral's documentation for Skills in Vibe Work ([[services/mistral-le-chat]]), the replacement for the old Agents and the closest equivalent of a custom GPT. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Skills are reusable instructions and resources; each Skill is a folder with a SKILL.md file and optional extra files, following the open Agent Skills standard.
- `c2` Users create a Skill under Context, then Skills, then New Skill, by filling in a title, a description, the SKILL.md instructions and optional files or folders.
- `c3` Users can also ask Work to "turn this into a Skill" from a chat, and Work drafts the SKILL.md for review.
- `c4` A Skill activates automatically when a task matches its description, or is invoked with `/` and the Skill name, or by naming it in the prompt.
- `c5` Personal Skills are visible only to their creator; Workspace Skills are shared across a workspace.
- `c6` Vibe Work ships built-in Skills, including deep-research, data-analysis and doc-coauthoring.
- `c7` Supporting files are subject to a file-count limit.
