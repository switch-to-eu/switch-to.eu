**Summary:** Startpage's steps for making [[services/startpage]] the default search engine in [[services/chrome]] on Android. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Startpage says Chrome must first recognise Startpage as a search engine; to do that, set the request method to GET on the Startpage settings page and run a search on startpage.com.
- `c2` Then open Chrome settings > Search engine and tap Startpage in the list of recently visited search engines.
- `c3` Startpage says to switch the setting back to POST afterwards if that is the user's preference.
- `c4` Startpage says that because of OpenSearch inconsistencies, several searches or visits may be needed before Chrome recognises Startpage.
