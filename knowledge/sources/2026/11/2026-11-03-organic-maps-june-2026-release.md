**Summary:** Release notes for the June 2026 version of [[services/organic-maps]], which added public transport routing, alternate routes and an experimental satellite layer.

**Claims**
- `c1` The June 2026 update added public transport routing by subway, light rail, bus and tram.
- `c2` The update added alternate routes: the shortest route is shown next to the fastest one.
- `c3` Satellite imagery is experimental and needs a custom raster tile server URL entered in settings, because the project's own imagery server is not ready.
- `c4` Walking and cycling routes now warn about steps, gates and lift gates.
- `c5` Bookmarks can use any colour, and GeoJSON tracks keep elevation and timestamps on import and export.
- `c6` Android got a new search interface and a new route planning interface.
