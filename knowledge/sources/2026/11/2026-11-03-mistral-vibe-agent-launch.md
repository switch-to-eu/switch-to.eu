**Summary:** Mistral AI's own announcement that its consumer chat assistant Le Chat ([[services/mistral-le-chat]]) was renamed Vibe and merged with its coding agent into one product, with Work Mode for chat and tasks and Code Mode for coding. It also gives the plan prices at launch and says the separate Chat mode will be retired.

**Claims**
- `c1` Mistral says Le Chat is now Vibe, one agent and one licence across work and code, and that every conversation, setting and plan carries over.
- `c2` Vibe has a Work Mode, available on web and mobile, for multi-step tasks, and a Code Mode for remote coding sessions.
- `c3` Vibe is served at chat.mistral.ai, with mobile apps on the App Store and Google Play.
- `c4` Users who were on Le Chat find their plan, history and settings in Vibe's Chat mode.
- `c5` Mistral says it will soon sunset Chat mode and that Le Chat history will be kept in Work Mode.
- `c6` Plans at launch: Free, Pro at $14.99 per month, Team at $24.99 per user per month, and Enterprise with custom deployments.
- `c7` Work Mode can schedule a prompt to run once or on a daily, weekly or monthly cadence.
- `c8` Vibe supports reusable skills, preset or custom, built on open standards.
