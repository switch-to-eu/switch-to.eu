**Summary:** Second read of Proton's support page for [[services/proton-lumo]], for parts [[2026-11-03-proton-lumo-privacy-help]] left out. Claims describe Proton's own practices. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Web search is optional and off by default. Proton says it picked search engines for privacy, performance, efficiency and reliability, and names none.
- `c2` On Free and Plus, chat history is stored on the device and synced to Proton servers with zero-access encryption.
- `c3` Guest conversations are erased at the end of each session.
- `c4` Proton says Lumo doesn't store metadata such as timestamps, IP addresses or chat context.
- `c5` Proton says Lumo's code is open source.
