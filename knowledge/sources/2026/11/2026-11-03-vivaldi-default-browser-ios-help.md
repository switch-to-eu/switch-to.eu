**Summary:** Vivaldi's help page on making [[services/vivaldi]] the default browser on iPhone and iPad. Published 2023-09-22; read on 2026-11-03.

**Claims**
- `c1` On iOS, go to Vivaldi menu > Settings > Default browser and tap Open Vivaldi Settings.
- `c2` In the iOS settings screen that opens, tap Default Browser App and select Vivaldi.
- `c3` The same screen can be reached from the iOS Settings app by finding Vivaldi in the list or by searching for it.
