**Summary:** Mistral's help-centre article explaining the rename of Le Chat to Vibe for existing users of [[services/mistral-le-chat]]. The page carries the date August 12, 2026.

**Claims**
- `c1` Le Chat has become Vibe, and the account, plan, conversations and saved content of existing users move with them.
- `c2` Vibe has three modes: Vibe Work (the productivity mode used in Le Chat, on web and mobile), Vibe Code (CLI, VS Code extension and web) and Vibe Chat (the turn-based conversation mode Le Chat was known for).
- `c3` The URL and login stay the same: chat.mistral.ai opens Vibe with existing conversations.
- `c4` Detailed product documentation moved to docs.mistral.ai.
- `c5` The help centre keeps account, billing, subscription, data governance, privacy, security and compliance articles.
