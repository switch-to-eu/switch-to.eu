**Summary:** The landing page of Proton's help centre for [[services/proton-drive]], read for its FAQ on apps, encryption, file size and freed storage. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Proton Drive is available in the web app and in apps for Windows, macOS, Android and iOS/iPadOS.
- `c2` File contents, file names and folder names are encrypted with the user's private key before leaving the device; Proton says it cannot access uploaded files.
- `c3` Some fields, such as file size, are not encrypted, so the server can sort files.
- `c4` The largest file that can be uploaded is limited only by the free storage left in the account.
- `c5` After files are deleted, it can take up to three hours before the storage space is fully freed.
