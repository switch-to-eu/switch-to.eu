**Summary:** Mistral's documentation for Projects in Vibe Work ([[services/mistral-le-chat]]), which group chats with their own tone, instructions and files, similar to ChatGPT Projects. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Projects are available on all plans, with limits on the number of Projects and chats per Project set on the pricing page.
- `c2` A Project is created with the New Project button next to the Projects header in the left sidebar.
- `c3` Each Project can have its own tone, its own instructions (via Customize) and uploaded files that every chat in it can use.
- `c4` A chat can belong to only one Project at a time; chats are moved by drag and drop or the folder icon in the chat header.
- `c5` Deleting a Project is permanent, but its chats return to the main history.
