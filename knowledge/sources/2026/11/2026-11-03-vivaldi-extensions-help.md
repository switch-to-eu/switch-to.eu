**Summary:** Vivaldi's help page on extensions in [[services/vivaldi]]: Chrome Web Store compatibility, importing extensions from [[services/chrome]], and managing them. First published 2016-01-29, no last-updated date shown; read on 2026-11-03.

**Claims**
- `c1` Because Vivaldi is built on Chromium, extensions from the Chrome Web Store can be installed in Vivaldi.
- `c2` Vivaldi says some Chrome extensions behave differently in Vivaldi, but most work fine.
- `c3` Extensions install from the Chrome Web Store with an Add to Vivaldi button. If the button is missing, the Web Store option under Settings > Privacy and Security > Google Extensions must be enabled.
- `c4` Extensions can be imported from Chromium-based browsers such as Chrome via File > Import from Applications or Files, with the source browser closed. Each imported extension is then enabled with its toggle on the Extensions page.
- `c5` Extensions that are not in the Chrome Web Store can be loaded unpacked after enabling Developer mode on the Extensions page.
- `c6` All extension buttons are grouped together and cannot be placed separately on different toolbars.
