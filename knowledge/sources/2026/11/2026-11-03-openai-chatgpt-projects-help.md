**Summary:** OpenAI's help article on Projects in [[services/chatgpt]]. The page said "Updated: 3 days ago" on November 3, 2026, so the published date is set to October 31, 2026. It does not say whether project files appear in the data export.

**Claims**
- `c1` Projects keep related chats, files and instructions together.
- `c2` Project instructions are set via the more-options menu, Project settings, and override global custom instructions inside the project.
- `c3` Files in a project can be previewed, downloaded or deleted from the project sources list.
- `c4` File limits per project: Pro up to 40 files, Plus and Go up to 25, Free up to 5.
- `c5` Projects can use default memory or project-only memory; shared projects always use project-only memory.
- `c6` Deleting a project permanently removes its chats, instructions and files stored only in the project.
- `c7` Project sharing is available on ChatGPT Free, Go, Plus, Pro, Business, Enterprise and Edu, on web and mobile.
