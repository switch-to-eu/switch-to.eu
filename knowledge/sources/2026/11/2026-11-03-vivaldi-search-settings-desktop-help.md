**Summary:** Vivaldi's desktop help page on search settings in [[services/vivaldi]]: default and private-window engines, nicknames, and the built-in engine list, which includes [[services/ecosia]], [[services/qwant]] and [[services/startpage]]. First published 2022-05-04; the page may have been updated since.

**Claims**
- `c1` The default is set under Settings > Search > Default Search Engine, or by ticking "Set as Default Search" on an engine under Settings > Search > Search Engines.
- `c2` A separate default for private windows is set under Settings > Search > Private Window Search Engine.
- `c3` Built-in engines listed include Bing, Yahoo, DuckDuckGo, Ecosia, Qwant (available by default in selected countries), StartPage, Wikipedia and Google.
- `c4` Search engine nicknames switch the engine for one search: type the nickname, a space, then the search term.
- `c5` An engine picked in the Search Field reverts to the default when the browser closes, unless "Keep Last Selected Search Engine" is enabled.
- `c6` Vivaldi notes that search suggestions have privacy implications and can be turned off or limited to nickname searches.
