**Summary:** Startpage's explanation of why [[services/startpage]] cannot be the default search engine in Safari, with a Mac workaround. The page shows no date, so the fetch date is used; it refers to Safari 13 (2019), so it may be old.

**Claims**
- `c1` Startpage says Safari 13 removed support for legacy extensions that controlled the URL bar, including Startpage's extension.
- `c2` Startpage says Safari users are therefore unable to set Startpage as their default search engine.
- `c3` Startpage asks Safari users to request its addition to Safari's list through Apple's Safari feedback form.
- `c4` As a workaround on Mac, Startpage suggests making it the home page, or using Safari's Quick Website Search by typing "startpage" followed by the query in the address bar.
