**Summary:** Proton's help article on creating and editing documents in Proton Docs, the editor inside [[services/proton-drive]]. The page shows no date, so the fetch date is used.

**Claims**
- `c1` On the web, a document is created with New → New document in Proton Drive.
- `c2` The maximum document size that can be created or edited in Proton Drive is 25 MB.
- `c3` Documents can also be created in the Android and iOS apps from Files → + → Create document.
- `c4` Docs supports comments, suggested edits, tables, lists, code blocks and text formatting.
