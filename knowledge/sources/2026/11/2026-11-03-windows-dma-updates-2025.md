**Summary:** Microsoft's post, first published 2025-06-02 with updates to 2025-08-28, on Windows changes in the EEA for the DMA. Relevant because it shows what Microsoft does instead of a search choice screen; links [[services/bing-search]] and [[services/microsoft-edge]].

**Claims**
- `c1` In the EEA, apps can provide web search results in Windows Search; a web search provider registered by an app is enabled automatically when the app is installed.
- `c2` In the EEA, users can reorder web search providers for Windows Search in Settings.
- `c3` The Microsoft Bing app, which supplies web results in Windows Search, opens web content in the default browser in the EEA.
- `c4` In the EEA, "Set default" for a browser in Windows Settings sets more link and file types and pins the browser to the taskbar unless the user unticks it; these changes reached retail PCs from July 2025.
- `c5` The post describes no search engine choice screen in Windows.
