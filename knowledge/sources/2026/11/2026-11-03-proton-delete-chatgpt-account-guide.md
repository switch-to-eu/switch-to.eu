**Summary:** Proton's guide to exporting data from and deleting a [[services/chatgpt]] account. Proton sells a competing AI assistant ([[services/proton-lumo]]) and promotes it at the end. It describes the export ZIP contents in more detail than OpenAI's help page.

**Claims**
- `c1` Proton says the ChatGPT export is a ZIP file with JSON files and an HTML file holding conversations, account information, uploaded or created images and other account data.
- `c2` Proton says the mobile apps send users to the web to export data.
- `c3` Proton says an export can take a few hours to several days, depending on how much data the account holds.
