**Summary:** Qwant's steps for making [[services/qwant]] the default search engine in Firefox desktop without its add-on. The page said "3 months ago Updated" when fetched; no exact date is shown, so the fetch date is used. Reliability is high for Qwant's own instructions; for Firefox's menus it is a third party describing another product.

**Claims**
- `c1` In Firefox, open the menu > Settings > Search, then choose Qwant in the Default Search Engine dropdown.
- `c2` If Qwant does not appear in the list, Qwant says to perform a search on qwant.com first and then return to the settings.
- `c3` Qwant can also be set as the home page under Settings > Home > Custom URL with `https://www.qwant.com`.
