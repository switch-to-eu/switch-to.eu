**Summary:** Apple's Safari for Mac guide page listing the Search settings. The page shows no date, so the fetch date is used. It does not list the available engines.

**Claims**
- `c1` Search settings are under Safari > Settings > Search.
- `c2` Safari on Mac has a "Search engine" setting for regular browsing and a separate "Private Browsing search engine" setting.
- `c3` Apple notes that with "Include search engine suggestions" on, the search engine may record the search terms the user types.
- `c4` "Enable Quick Website Search" lets users search within a site by typing the site's name followed by the search term in the Smart Search field.
