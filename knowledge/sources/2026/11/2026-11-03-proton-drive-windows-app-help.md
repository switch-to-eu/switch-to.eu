**Summary:** Proton's help article on installing and using the Windows app of [[services/proton-drive]]. The page shows no date, so the fetch date is used.

**Claims**
- `c1` The Windows app is offered for Windows 11/10 on x64 (Intel or AMD) and on ARM64.
- `c2` After sign-in, the app offers to sync folders from the computer and asks for a default location for synced files; it starts with the computer by default.
- `c3` Synced files are stored in the My files folder; folders cannot be created in the root of the Proton Drive folder, only inside My files.
- `c4` The app window has an Activity view with real-time sync progress, file sizes and sync errors.
- `c5` A "Photos import" section imports photos from a local folder or from Google Photos.
- `c6` Sync can be paused from the system tray icon.
