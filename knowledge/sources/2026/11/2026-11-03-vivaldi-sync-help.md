**Summary:** Vivaldi's help page on Vivaldi Sync in [[services/vivaldi]]: the Vivaldi account, the separate encryption password, what syncs, where the data is stored and how to delete it. It is the replacement for Chrome's Google-account sync in [[services/chrome]]. First published 2017-11-29, no last-updated date shown; read on 2026-11-03.

**Claims**
- `c1` Sync requires logging in with a Vivaldi account, which can be created in the browser's Settings or on Vivaldi.net.
- `c2` After logging in, the user sets a separate encryption password of at least 12 characters. Vivaldi says this password is used only on the device and never sent to Vivaldi, so Vivaldi cannot decrypt synced data.
- `c3` Synced data types are bookmarks and Speed Dials, some settings, saved passwords, autofill data, history, extensions, web apps, Reading List, open tabs, and notes without attachments.
- `c4` Vivaldi stores Sync data on its own servers in Iceland.
- `c5` If the encryption password is forgotten and no device still holds the data, synced data cannot be recovered unless a backup encryption key was saved beforehand.
- `c6` Vivaldi says Sync is not meant to be used as a backup service.
- `c7` Reset Remote Data in Sync settings deletes the synced data from Vivaldi's servers.
- `c8` Syncing a separate user profile currently needs a separate Vivaldi account.
- `c9` With tab sync on, Send to Your Devices (right-click a tab) opens a page on another synced device.
