**Summary:** Qwant's page on using [[services/qwant]] in Safari on Mac. It confirms Safari has no built-in Qwant option and offers a Safari extension instead. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Qwant says Safari does not include Qwant in its native list of search engines.
- `c2` On Mac, the "Qwant for Safari" extension is available from the Mac App Store and must be enabled under Safari > Settings > Extensions.
- `c3` Qwant says the extension sets Qwant as the default search engine.
- `c4` Without the extension, Qwant's manual option on Mac only sets qwant.com as the home page for new windows and tabs.
- `c5` Qwant refers iPhone and iPad users to a separate article, "Set Qwant as the Search Engine in Safari iOS", which was not listed in Qwant's help center on the fetch date.
