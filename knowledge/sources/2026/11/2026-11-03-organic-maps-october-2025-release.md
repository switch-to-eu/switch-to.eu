**Summary:** Release notes for the 23 October 2025 version of [[services/organic-maps]]. It lets EU iPhone users make Organic Maps their default navigation app and recaps the 7 October release that added GeoJSON import.

**Claims**
- `c1` Users in the EU can set Organic Maps as the default navigation app on iOS under Settings > Apps > Default Apps > Navigation.
- `c2` The release notes say the previous update, of 7 October 2025, added GeoJSON import.
- `c3` GeoJSON imported from uMap (umap.openstreetmap.fr) should keep all its metadata.
- `c4` The release added Slovenian interface translations and Slovenian voice guidance.
