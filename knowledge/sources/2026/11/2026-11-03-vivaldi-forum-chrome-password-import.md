**Summary:** A user thread on Vivaldi's forum about Chrome passwords failing to import into [[services/vivaldi]], with replies from users and volunteer helpers; one reply includes a screenshot dated June 2025. User reports only. Thread started 2023-10-11; read on 2026-11-03.

**Claims**
- `c1` Users in the thread report that importing Chrome passwords into Vivaldi did not work for them.
- `c2` Helpers in the thread suggest exporting a .csv from Chrome's password manager and importing it at vivaldi://password-manager/settings.
- `c3` A forum helper says the old PasswordImport flag was removed from Chromium and is no longer needed, because import and export now sit in the password manager settings.
- `c4` One user reports that clicking Import in the password settings did nothing for them, even after restarting Vivaldi.
