**Summary:** Microsoft's privacy controls page for the new consumer Copilot app (available since 2026-08-18). No page date found, so the fetch date is used.

**Claims**
- `c1` The page's sections are Memory, Chat history, Web search, Personalized advertising and Import browser data from Microsoft Edge; a model-training setting is not listed.
- `c2` Copilot chats can be used to personalise Bing, Edge and MSN, and activity in those products can personalise Copilot, under a "shared experiences" setting.
- `c3` Personalised ads in Copilot may use chat history, saved memories and other Microsoft data; users can turn off "Allow ads personalization".
- `c4` Copilot does not show personalised ads to users under 18.
- `c5` Users can import Edge browsing data into the Copilot app, including cookies, history, payment info, passwords and autofill data.
