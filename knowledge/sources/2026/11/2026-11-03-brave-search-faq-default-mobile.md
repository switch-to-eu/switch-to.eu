**Summary:** Brave's FAQ for Brave Search. Used only for the steps to change the default search engine in the [[services/brave]] apps on Android and iOS. The page shows no date, so the fetch date is used.

**Claims**
- `c1` On Android, the path is Menu > Settings > Search Engines > Standard Tab, then select the engine.
- `c2` On iOS, the path is Main menu > Settings > Search Engines > Standard Tab, then select the engine.
- `c3` On desktop, right-click the address bar, choose Manage search engines, then use the ⋮ menu next to an engine and "Make default".
