**Summary:** Qwant's page on its [[services/chrome]] extension for [[services/qwant]]. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Qwant says the extension sets Qwant as Chrome's default search engine and as the home page for new tabs.
- `c2` Qwant says the extension also blocks trackers, reducing cookies and ads.
- `c3` The extension is installed from the Chrome Web Store (Add to Chrome > Add extension) and can be disabled or removed under Extensions > Manage extensions.
