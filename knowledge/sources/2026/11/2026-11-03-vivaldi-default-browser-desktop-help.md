**Summary:** Vivaldi's help page on setting [[services/vivaldi]] as the default browser on Windows, macOS and Linux. Published 2024-02-06; read on 2026-11-03.

**Claims**
- `c1` On Windows, Settings > General > Startup > Default Browser > Set as Default opens the Windows default apps settings, where Vivaldi is chosen under Web Browser.
- `c2` On macOS, Preferences > General > Startup > Default Browser > Set as Default, then confirm with Use "Vivaldi" in the system dialog.
- `c3` On Linux, Settings > General > Startup > Default Browser > Set as Default.
- `c4` Until Vivaldi is the default, it asks at every start whether to become the default browser. Unticking Check on Startup in the same section stops the question.
