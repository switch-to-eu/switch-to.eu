**Summary:** Vivaldi's desktop help page on importing data from other browsers and files, and exporting it again. It covers what the importer brings over from Chrome and other Chromium browsers into [[services/vivaldi]], which matters for anyone leaving [[services/chrome]]. The page shows a first-published date of 2021-03-11 and no last-updated date; read on 2026-11-03.

**Claims**
- `c1` On desktop, the importer is at Vivaldi menu > File > Import from Applications or Files: pick the source browser or file, then click Start Import.
- `c2` Bookmarks can be imported from another browser on the same computer or from a bookmarks HTML file.
- `c3` Depending on the source browser, passwords and browsing history can be imported in the same run as bookmarks.
- `c4` Importing open tabs works only from Chromium-based browsers such as Chrome, Edge, Opera and Brave.
- `c5` Extensions can be imported from Chromium-based browsers such as Chrome. The source browser must be closed first, and after the import each extension has to be switched on with its toggle on the Extensions page.
- `c6` Passwords can also be imported from a .csv file at vivaldi://password-manager/settings, under Import passwords > Select file.
- `c7` Vivaldi exports bookmarks as an HTML file (File > Export Bookmarks) and passwords as a .csv file, and warns that a password .csv is readable by anyone with access to it.
- `c8` To move data between Vivaldi installations the page recommends Sync. Copying a whole profile folder does not carry over saved passwords and cookies.
