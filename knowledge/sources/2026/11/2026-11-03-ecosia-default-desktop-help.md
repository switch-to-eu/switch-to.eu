**Summary:** Ecosia's desktop guide for making [[services/ecosia]] the default search engine in Chrome, Safari, Edge, Firefox, Brave, Opera and Vivaldi, or using its extension or the [[services/ecosia-browser]]. The page shows no date, so the fetch date is used. Reliability is high for Ecosia's own instructions; for other browsers' menus it is a third party.

**Claims**
- `c1` Ecosia says Chrome may only show the top search engines in a user's country, so Ecosia may not be listed; its fallback is the Ecosia extension or a manual entry.
- `c2` The manual Chrome entry uses Manage search engines and site search with the URL `https://www.ecosia.org/search?q=%s&addon=manualopensearch`, then the three-dots menu > Make default.
- `c3` Ecosia says its Chrome and Firefox extensions set both the default search engine and the home page.
- `c4` In Safari on Mac, Ecosia says to click the magnifying glass next to the address bar and select Ecosia from the dropdown.
- `c5` In Edge, Ecosia says to go to Settings > Privacy, search, and services > Address bar and search and select Ecosia; it notes this may not be available in every country.
- `c6` Ecosia says that as of December 2024, Ecosia is selectable in Firefox's Default Search Engine list only in Austria, Switzerland, Germany, Belgium, Italy, the Netherlands, Spain and Sweden; elsewhere it points to its extension.
- `c7` In Brave, the path Ecosia gives is Settings > Search engine > Change, then select Ecosia and Set as default.
