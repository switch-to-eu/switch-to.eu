**Summary:** Google's developer reference for the "Saved" export, which holds saved collections (lists) from Google Search and [[services/google-maps]]. It lists the CSV format and its fields. Page last updated 2025-03-26.

**Claims**
- `c1` Saved collections contain items saved on Google Search, Maps and other services, and are exported as CSV.
- `c2` The fields listed for a saved item are title, note, URL, tags and comment, plus an optional collection description on the first line of the CSV.
- `c3` The field list names no latitude, longitude or address field for saved items.
- `c4` For a Maps item, the URL example is a google.com/maps/place link.
- `c5` Images uploaded to a collection are exported as image files.
