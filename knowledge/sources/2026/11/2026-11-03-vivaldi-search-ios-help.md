**Summary:** Vivaldi's help page on search in [[services/vivaldi]] for iOS. The page's metadata date is not usable, so the fetch date is used.

**Claims**
- `c1` The default for regular tabs is set under Vivaldi menu > Settings > Search Engine > Standard Tab.
- `c2` Private tabs have their own default under Vivaldi menu > Settings > Search Engine > Private Tab.
- `c3` The built-in list includes Ecosia (nickname e) and StartPage (nickname s).
- `c4` Custom engines are added under Settings > Search Engine > Add Custom Search Engine.
