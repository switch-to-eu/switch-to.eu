**Summary:** Microsoft's FAQ for the [[services/microsoft-edge]] mobile apps. Used only for the section on the default search engine. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Bing is the default search engine for Microsoft Edge on mobile.
- `c2` To change it, tap the menu (…) > Settings > General > Default search engine, then select an engine from the options shown.
- `c3` If the wanted engine is not listed, Microsoft says to visit that search engine in the browser and then check the list again; if it still does not appear, send feedback.
