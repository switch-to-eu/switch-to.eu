**Summary:** rclone's documentation for its [[services/proton-drive]] backend, the route third-party guides use for direct cloud-to-cloud moves from [[services/google-drive]]. The page shows no date; the server reported 9 October 2026 as its date. Claims are about rclone's own backend, not about Proton's products.

**Claims**
- `c1` The Proton Drive backend was added in rclone v1.64.0 and is rated Tier 4, which rclone defines as experimental ("use with care; expect gaps/changes").
- `c2` rclone says Proton Drive does not publish API documentation, so the backend was built by reading Proton's open-source client code and observing browser traffic.
- `c3` rclone labels the backend as beta and says some accounts may not be compatible because the Proton Drive protocol has changed over time.
- `c4` The Proton Drive encryption keys must have been generated by a regular browser login first, or rclone sign-in fails.
- `c5` The backend does not support updating modification times yet.
- `c6` A cancelled or failed upload leaves a draft that makes a later upload of the same file report a conflict, unless the replace-existing-draft option is set.
