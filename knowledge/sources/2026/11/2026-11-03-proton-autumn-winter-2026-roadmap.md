**Summary:** Proton's roadmap post for the six months from October 2026, covering [[services/proton-mail]], [[services/proton-drive]], Pass, VPN and Lumo. For Drive it announces an Easy Switch import from [[services/google-drive]] and a Linux beta. These are plans, with no dates given.

**Claims**
- `c1` Proton says moving data from another cloud storage provider currently means downloading everything to a device and uploading it again by hand, which it calls time-consuming and difficult.
- `c2` Proton says it is building an "Easy Switch from Google Drive" so data no longer has to make that round trip; the post covers the next six months and gives no release date.
- `c3` Proton says it is working towards a beta of an official Proton Drive app for Linux, likely starting as a headless sync daemon that keeps a configurable list of folders up to date.
- `c4` Proton says macOS will gain folder sync for any chosen folder, as on Windows, and calls its absence the biggest missing feature of the Mac client.
- `c5` For Docs and Sheets, Proton lists planned features including ODT import and export in Docs, editing Sheets on mobile, page breaks in Docs and a dark theme.
- `c6` Proton says search on mobile and web will extend beyond file names, rolled out in increments.
