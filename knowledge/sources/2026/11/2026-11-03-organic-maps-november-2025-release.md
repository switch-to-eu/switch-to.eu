**Summary:** Release notes for version 2025.11.25 of [[services/organic-maps]]. It names Google Takeout's `Saved Places.json` file from [[services/google-maps]] as supported by the improved GeoJSON import. The URL is dated 2025-11-26; the page metadata says 2025-11-28.

**Claims**
- `c1` The release improved GeoJSON import, including `Saved Places.json` bookmarks from Google Takeout.
- `c2` Files ending in `.json` can now be imported as GeoJSON.
- `c3` A new setting highlights downloaded map regions in purple.
- `c4` On iOS, a bookmark or track can be renamed directly on its place page, and its list changed by tapping the list name.
- `c5` When a track is moved to a list, that list becomes the default for new bookmarks and tracks.
