**Summary:** Mistral's page comparing the Vibe modes of [[services/mistral-le-chat]] and mapping each legacy Chat feature to its new equivalent. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Work is available in the Vibe web and mobile apps and handles both quick conversations and multi-step tasks, switched with a fast/think toggle.
- `c2` Legacy Agents map to Skills, invoked with `@`.
- `c3` Legacy Think mode maps to the fast/think toggle, and legacy Deep Research to the Deep Research Skill.
- `c4` Legacy Code Interpreter maps to the native Code Interpreter in Work, available on paid plans.
- `c5` Legacy Memories map to the Knowledge Base.
- `c6` Work offers Temporary Chat, excluded from history, search, memory and model training.
- `c7` Work can connect to tools such as Gmail, Outlook, Slack, Notion, Google Drive and SharePoint through Connectors.
