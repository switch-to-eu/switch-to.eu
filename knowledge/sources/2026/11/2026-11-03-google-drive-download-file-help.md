**Summary:** Google's help article on downloading files from the [[services/google-drive]] web app, including saving Docs, Sheets and Slides in other formats. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Files are downloaded from drive.google.com by right-clicking and choosing Download; several files can be selected with Ctrl (Windows) or Command (Mac).
- `c2` A file opened in Docs, Sheets, Slides or Vids can be saved in another format through File → Download, for example PDF, Microsoft Word (.docx), PowerPoint (.pptx) or JPEG.
- `c3` The owner of a file can disable downloading, printing and copying for people with only view or comment access.
- `c4` Blocking third-party cookies in Chrome prevents downloads from the Drive web app unless drive.google.com is allowed.
