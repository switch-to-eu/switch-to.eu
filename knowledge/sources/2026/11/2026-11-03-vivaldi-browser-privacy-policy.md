**Summary:** The privacy policy for the [[services/vivaldi]] browser, issued by Vivaldi Technologies AS. It describes the daily usage ping, partner bookmarks, the password store, and the Google services the browser uses (Safe Browsing, autofill). The page says "Last modified and effective: December 15, 2023"; read on 2026-11-03.

**Claims**
- `c1` Each Vivaldi installation profile gets a unique user ID. Every 24 hours the browser sends that ID, the version, CPU architecture, screen resolution and time since the last message to Vivaldi's servers in Iceland.
- `c2` Vivaldi removes the last octet of the IP address and stores an approximate location, to count active users and their geographic spread.
- `c3` Vivaldi receives shared revenue from some partner sites in the default bookmarks, and users can remove those bookmarks.
- `c4` Vivaldi says browsing history, typed searches and downloads stay in the local profile and that it has no access to them.
- `c5` On desktop and Android, Vivaldi uses Google's Safe Browsing API to check sites against a phishing and malware list. On desktop it can be switched off in Privacy settings.
- `c6` When search suggestions are on, what the user types is sent to the chosen search engine.
- `c7` Google's form autofill feature is enabled by default. Vivaldi says it does not send the user's personal information to Google.
- `c8` The policy is issued by Vivaldi Technologies AS, which says it does not share or sell user information to third parties.
