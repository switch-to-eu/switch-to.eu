**Summary:** Mistral's documentation for account-wide custom instructions in Vibe Work ([[services/mistral-le-chat]]), the equivalent of ChatGPT's custom instructions. No character limit is stated. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Custom instructions are set from the left sidebar under Context, then Instructions, where the user picks a Tone and enters instructions.
- `c2` Instructions apply to all new tasks after saving; existing tasks are not affected.
- `c3` When a Skill is active, the Skill's instructions take precedence over custom instructions.
- `c4` Inside a Project, custom instructions and the Project's context apply together.
- `c5` Mistral advises keeping custom instructions short and not putting secrets or credentials in them.
