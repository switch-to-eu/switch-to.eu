**Summary:** Proton's help article on opening existing files in Proton Docs, the editor inside [[services/proton-drive]], and on exporting from it. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Proton Docs can open and edit .docx, .txt, .md and .html files stored in Proton Drive.
- `c2` Documents can be downloaded from Docs as .docx, .html, .txt, .md and .pdf.
- `c3` A .docx file is opened through the ⋮ menu → "Open in Docs", or by double-clicking it and choosing "Open in Docs" in the preview.
- `c4` Editing an existing document in Docs creates a new copy with the same name in a different format; the original file is kept.
- `c5` In the Windows and macOS apps, a Doc exists locally only as a small placeholder that opens docs.proton.me in the browser.
- `c6` Moving or copying a Doc placeholder out of the synced folder does not create a usable copy: the placeholder becomes a 0-byte file and the document is moved to Proton Drive's Trash. Proton says to use Download instead.
