**Summary:** Startpage's steps for making [[services/startpage]] the default in [[services/chrome]] on iPhone. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Startpage says to select GET on its settings page, perform a search on startpage.com, then open Chrome settings > Search Engine and tap Startpage under recently visited search engines.
- `c2` Startpage says the GET setting is only needed for adding Startpage to Chrome and can be switched back to POST afterwards.
