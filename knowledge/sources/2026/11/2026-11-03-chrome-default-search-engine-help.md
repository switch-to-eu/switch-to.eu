**Summary:** Google's help article on choosing the address-bar search engine in [[services/chrome]], read in its Computer, Android and iPhone & iPad versions. It covers the default setting, adding a custom engine with a `%s` URL, and the EEA choice prompt. The page shows no date, so the fetch date is used. Relevant to moving off [[services/google-search]] to [[services/qwant]], [[services/ecosia]] or [[services/startpage]].

**Claims**
- `c1` Google says that in some countries Google Search is Chrome's default search engine, and in others users may be asked to choose their default search engine.
- `c2` On a computer, the path is More > Settings > Search engine, then select Change under "Search engine" and pick a new default.
- `c3` On a computer, Settings > Search engine > Manage search engines and site search lets users add a site search (name, shortcut, and a results URL with `%s` in place of the query) and set it as default with More > Make default.
- `c4` Some search sites only appear under "Inactive shortcuts" after the user has searched on that site; they can be added with Activate.
- `c5` On Android, the path is More > Settings > under "Basics" tap Search engine, then select the engine.
- `c6` On iPhone and iPad, the path is More > Settings > Search engine, then select the engine.
- `c7` On Android and iOS, recently visited search engines are added as options in the list.
- `c8` In some countries, custom site searches cannot be set as default for Guest profiles.
- `c9` Google says unexpected changes to the search engine can be a sign of malware, and work or school admins can lock the default search engine.
