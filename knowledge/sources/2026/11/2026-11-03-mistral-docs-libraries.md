**Summary:** Mistral's documentation for Libraries in Vibe Work ([[services/mistral-le-chat]]), persistent document collections that chats can search. It lists upload limits and accepted file formats. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Libraries are persistent knowledge bases built from uploaded documents and web pages, with no limit on the number of Libraries.
- `c2` Up to 100 files can be uploaded at once, with a maximum of 100 MB per file.
- `c3` Accepted formats include PDF, Word, PowerPoint, ODT, EPUB, RTF, Excel, CSV, PNG, JPEG, TXT, Markdown, JSON, JSONL, XML, YAML, code files and EML/MSG email files.
- `c4` HTML is not in the list of accepted formats.
- `c5` Processing uses a monthly allowance shared across all Libraries; when it runs out, new uploads pause until it resets.
- `c6` Answers from a Library include numbered footnotes linked to the source passages.
