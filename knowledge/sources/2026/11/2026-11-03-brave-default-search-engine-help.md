**Summary:** Brave's help article on the address-bar search engine in the [[services/brave]] desktop browser, including manual adding of engines. Its screenshots use [[services/qwant]] as the example default. The page shows no date, so the fetch date is used.

**Claims**
- `c1` The default is set under Menu > Settings > Search Engine, with separate defaults for normal and private windows.
- `c2` Under Manage Search Engines, the three-dots menu next to an engine offers "Make default" and "Delete".
- `c3` With "Index other search engines" on, Brave indexes engines that follow the OpenSearch specification as the user visits them; they appear under "Inactive Shortcuts" and need "Activate" before use.
- `c4` An engine can be added manually with Add: a name, a keyword, and a URL with `%s` in place of the query.
- `c5` Brave says engines can also be added by visiting the search site and performing a search.
- `c6` "Improve search suggestions" is off by default and disabled in private browsing.
