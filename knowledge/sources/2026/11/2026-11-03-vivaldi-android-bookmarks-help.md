**Summary:** Vivaldi's help page on bookmarks in [[services/vivaldi]] for Android, including importing and exporting a bookmarks HTML file. First published 2019-09-09, no last-updated date shown; read on 2026-11-03.

**Claims**
- `c1` On Android, bookmarks can be imported from a bookmarks HTML file via the Bookmarks Panel > 3-dot menu > Import Bookmarks.
- `c2` Imported bookmarks land in a folder named "Imported", with a number added when several files are imported.
- `c3` For bookmarks from Vivaldi on another device, the page recommends Sync with the same Vivaldi account.
- `c4` Vivaldi on Android can export bookmarks to an HTML file, saved in the device's Downloads folder.
