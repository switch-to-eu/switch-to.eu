**Summary:** The privacy statement for Vivaldi Sync in [[services/vivaldi]]: where encrypted sync data is stored, which metadata Vivaldi keeps and for how long. The page says "Last modified and effective: July 13, 2018"; read on 2026-11-03.

**Claims**
- `c1` Sync data is encrypted in the browser and sent as individually encrypted entries to Vivaldi servers in Iceland.
- `c2` Vivaldi's servers are hosted at the Hringdu data centres in Iceland.
- `c3` Alongside the encrypted data, Vivaldi keeps metadata: which user each entry belongs to, entry type, deletion flag, parent entry, the client that created it, creation and modification times, and when the user started and last used Sync.
- `c4` Server error logs containing a user name and timestamp are kept for up to 30 days.
- `c5` Sync data is kept for up to one year after the user last used Sync, or until the user asks for deletion.
- `c6` Vivaldi says it will not transfer personal data to third parties except as required by law or law enforcement.
