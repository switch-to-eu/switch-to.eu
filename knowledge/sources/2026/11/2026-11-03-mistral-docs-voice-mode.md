**Summary:** Mistral's documentation for voice input in Vibe Work ([[services/mistral-le-chat]]). It describes speech-to-text input; a section titled "Talk with Work in conversation mode" exists but was empty when read. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Voice mode transcribes speech into text that the user can review, edit and send as a prompt.
- `c2` Voice mode is available on the web app and the iOS and Android apps, on all plans.
- `c3` Supported languages include English, French, Spanish, German, Italian, Portuguese and Dutch, among 13 listed.
- `c4` On Free, Pro and Student plans, voice messages may be used to train Mistral's models unless the user opts out.
- `c5` On Team and Enterprise plans, voice messages are not used for training by default.
