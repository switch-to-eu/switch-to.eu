**Summary:** Proton's guide to the web app of [[services/proton-drive]]: uploading, Docs and Sheets, sharing, downloads, version history and the Computers and Photos tabs. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Files and folders can be dragged from the computer's file manager into the web app, or uploaded with dedicated upload buttons; items go into the folder currently open.
- `c2` New documents are created with New → New document (Proton Docs) and new spreadsheets with New → New spreadsheet (Proton Sheets).
- `c3` Files and folders can be shared by secure link, with optional password protection and expiration, or by inviting specific people by email with view or edit rights.
- `c4` A Shared tab lists everything the user shared, with options to manage access or stop sharing; a Shared with me tab lists items others shared.
- `c5` Downloading several items at once produces a ZIP archive.
- `c6` A Computers tab shows files synced from the Windows or Mac desktop app, and a Photos tab handles photos and albums.
