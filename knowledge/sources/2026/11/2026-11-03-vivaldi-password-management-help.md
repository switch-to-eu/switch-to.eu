**Summary:** Vivaldi's desktop help page on its built-in password manager in [[services/vivaldi]]: saving, viewing, deleting, importing and exporting passwords. Relevant to moving saved logins out of [[services/chrome]]. First published 2019-02-21, no last-updated date shown; read on 2026-11-03.

**Claims**
- `c1` Vivaldi's built-in password manager offers to save logins and can be switched off under Settings > Privacy and Security > Passwords by unticking Save Webpage Passwords.
- `c2` To import passwords from another browser, the source browser must be closed first, then the import runs from Vivaldi menu > File > Import from Applications or Files.
- `c3` The page says password import is not possible from all browsers.
- `c4` Passwords can be imported from a .csv file at vivaldi:password-manager/settings, in the Import passwords section.
- `c5` Passwords can be exported to a .csv file from Settings > Privacy and Security > Passwords > Export passwords, after entering the computer's password.
- `c6` All saved passwords are deleted via Vivaldi menu > Tools > Delete Browsing Data, with Passwords and All Time selected. This also removes the stored Sync login password.
- `c7` Instead of the built-in manager, password manager extensions can be installed from the Chrome Web Store.
