**Summary:** Proton's list of file types that [[services/proton-drive]] can preview on web, iOS, Android and the CLI. The page shows no date, so the fetch date is used.

**Claims**
- `c1` The web app previews most text file types, including TXT and DOCX, but not DOC or RTF.
- `c2` Excel (.xlsx) files cannot be opened directly in Proton Drive; they are previewed and edited through Proton Sheets.
- `c3` The web app previews PDF, common image formats and video formats supported by the browser.
- `c4` The web app's list does not name PowerPoint (.pptx) files.
- `c5` The iOS app previews more formats, including Microsoft Office files and iWork documents, through Apple's Quick Look.
