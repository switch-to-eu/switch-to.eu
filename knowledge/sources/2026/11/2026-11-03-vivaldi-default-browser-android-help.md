**Summary:** Vivaldi's help page on making [[services/vivaldi]] the default browser on Android. Published 2023-09-22; read on 2026-11-03.

**Claims**
- `c1` On Android, open the Vivaldi menu and select Set as default browser, then tap Browser app and choose Vivaldi Browser.
- `c2` The same toggle is in Vivaldi's Settings, in the Web Pages section.
- `c3` Alternatively, Android Settings > Apps > Default Apps sets Vivaldi as the default browser app.
