**Summary:** Startpage's steps for making [[services/startpage]] the default in desktop [[services/chrome]], through its extension. The page shows no date, so the fetch date is used.

**Claims**
- `c1` Startpage's route for Chrome is add.startpage.com, which leads to a Chrome Web Store extension (Add to Chrome > Add extension).
- `c2` Startpage says that if the "Add to Chrome" button does not show, promotional messaging must be enabled on the Startpage settings page.
- `c3` Startpage says Chrome may show a popup asking the user to confirm the search change, and the user should click "Keep Changes" to stay with Startpage.
