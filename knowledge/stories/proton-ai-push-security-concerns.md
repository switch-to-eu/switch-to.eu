## Summary
404 Media reported on 29 October 2026, from nine current and former employees and internal messages and recordings, that Proton CEO Andy Yen pushed staff to write code with AI and dismissed a request to security-test code before release as "loser thinking". [[2026-11-03-404media-proton-ai-reckoning#c1]] [[2026-11-03-404media-proton-ai-reckoning#c2]] [[2026-11-03-404media-proton-ai-reckoning#c3]] The readable reporting describes no breach of user data and does not say Proton's encryption is weaker. [[2026-11-03-heise-proton-slack-leak]]

Yen apologised on 30 October, said AI use will never be at the expense of security, said security review has been added rather than removed, and called one reported detail (tracking software on staff laptops) false. [[2026-11-03-reddit-andy-yen-message-to-community#c1]] [[2026-11-03-reddit-andy-yen-message-to-community#c3]] [[2026-11-03-reddit-andy-yen-message-to-community#c4]] [[2026-11-03-reddit-andy-yen-message-to-community#c5]] He promised to publish how Proton does code and security reviews and its AI policies, with no date. [[2026-11-03-reddit-andy-yen-message-to-community#c9]] Proton's CTO published a memo on 1 November saying most human code review will end. [[2026-11-03-proton-ai-manifesto#c5]]

## Open questions
- When will Proton publish how it does code and security reviews, and its AI policies? Yen gave no date.
- Will that publication say where people still review code before release, given the CTO's memo?
- Will a new independent audit cover AI-written code?
- What does the 90% figure measure? It comes from a meeting recording, reported through heise.
- 404 Media reports Yen said this is the last year Proton will hire engineers. [[2026-11-03-404media-proton-ai-reckoning#c5]] Yen's post does not address this. Is it still the plan?
