## Where A and B agree, and what B added

- **Focus visibility (B, confirmed):** header dropdown triggers and Radix tab panels had no visible focus ring. Cause: Tailwind v4's `outline-none` sets `--tw-outline-style: none`, which `focus-visible:outline-2` then inherits. Neither the earlier hand audit nor A caught this.
- **Document structure (B):** no skip link, and two nested `<main>` elements on every page.
- **Reduced motion (B):** correct. All shape animations stop under `prefers-reduced-motion`.
- **Article measure (B):** about 58 to 63 characters per line at 1280. That's within the Read target and agrees with A's strength #1.
- **Contrast (B):** 0 failures on the sample. Text over SVG shapes is unmeasurable, which A's visual review covers.
- **200% text zoom (B):** overflow when the root font size is forced. Real browser zoom at 200% on a 1280px screen gives a 640px viewport, which the 375px run covers with no overflow. Recorded, not treated as a defect.
- **False positives (B):** the `/_vercel/insights` 404 (only exists on Vercel) and aborted `_rsc` prefetches.

## Strengths to keep

1. The article reading column: about 60 characters per line, 18px/1.75, a calm column inside a brand-owned frame.
2. The masthead puts the site's main action (search for the service you want to leave) in working form.
3. Trust is designed in, not claimed: source counts, a first-class sources box, and concrete "How we work" rules.

## Follow-up (2026-11-03): impeccable's own engine

The owner approved running the impeccable launcher. Its binary (engine 0.1.18) was downloaded from the project's GitHub releases and checked against `engine-checksums.txt`. Steps:

1. **`impeccable context`** loaded PRODUCT.md. It flagged `INCUMBENT_WORLD_UNDOCUMENTED` (no DESIGN.md) and `MANUAL_DETECTOR_REQUIRED`.
2. **`impeccable detect --json`** over `apps/website/components`, `apps/website/app/(frontend)`, `packages/blocks/src/components` and `packages/ui/src/components`. One finding: `side-tab` (2px coloured left border) in `components/ui/service-issues.tsx`. That component was unused, so it was deleted. **Rerun: `[]`, exit 0.**
3. **Browser overlay** (`live-server` plus injected `detect.js`) on `/en`, `/en/news` and an article, at 1280px and 390px. First pass found:
   - low-contrast placeholders (search 2.2:1, newsletter 4.2:1): fixed (raised to 75% and 85%)
   - stragglers (single-word last lines) in 7 paragraphs: fixed (`text-wrap: pretty` on p, dd, li and blockquote)
   - sample-notice line length about 90 characters: fixed (`max-w-[36rem]`)
4. **Second overlay pass:** two findings remain. Both are intentional:
   - **`.eu` in the header logo (1.3:1):** it's the logotype, which WCAG 1.4.3 exempts. Changing it is a brand decision.
   - **Oversized h1 (96px):** PRODUCT.md pins the home hero to Anton at `clamp(3.5rem, 12vw, 14rem)`. Impeccable's rule is "the brief wins". The current 6rem cap is already a compromise.
5. `live-server stop --keep-inject`. No project files were touched by the overlay.

Regression after these changes: `a11y-audit.cjs --keyboard` 22/22 clean. Build, lint, typecheck and the 4 Playwright smoke tests pass.
