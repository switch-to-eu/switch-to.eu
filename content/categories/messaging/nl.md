### Stappen de mensen met wie je praat mee over?

Een messenger werkt alleen als je contacten dezelfde app gebruiken. Signal kost niets, dus niemand die je uitnodigt hoeft te betalen.

Threema kost eenmalig €6. Dat is weinig, maar iedereen die je uitnodigt betaalt hetzelfde. Session en Element zijn gratis. Session geeft iedereen een lange willekeurige ID in plaats van een telefoonnummer, en bij Element kies je eerst een server. Reken dus op wat meer uitleg.

### Wil je je telefoonnummer voor jezelf houden?

Signal heeft een telefoonnummer nodig om een account aan te maken. Standaard zien alleen mensen die je nummer al in hun contacten hebben je nummer. Alle anderen vinden je via een gebruikersnaam die je deelt.

Threema en Session geven je een willekeurige ID en hebben geen telefoonnummer nodig. Session vraagt ook geen e-mailadres. Je berichten gaan via een gedecentraliseerd netwerk van ruim 1.500 nodes, en volgens Session verbergt dat je IP-adres.

Element vraagt om een gebruikersnaam op de Matrix-server die je kiest. Een e-mailadres is optioneel.

### Waar zitten de bedrijven, en waar staan de servers?

Geen enkele messenger op deze pagina heeft zijn hoofdkantoor in een EU-lidstaat. Threema AG zit in Pfäffikon in Zwitserland, en het Duitse investeringsbedrijf Comitis Capital is sinds 2026 eigenaar van Threema. Een Zwitserse stichting beheert Session. Het hoofdkantoor van Element staat in Londen. Signal is een Amerikaanse non-profit in Mountain View, Californië.

Ook de servers verschillen. Volgens Threema staan alle servers in Zwitserland. Volgens de voorwaarden van Signal gaan je versleutelde gegevens en metadata naar de Verenigde Staten en andere landen. Session draait op een eigen netwerk van nodes in plaats van op bedrijfsservers. Bij Element staat je account op de Matrix-server die je kiest, of op je eigen server.

Alle vier zeggen dat ze je berichten end-to-end versleutelen, dus wie de servers beheert, kan ze niet lezen.

### Hoe groot zijn je groepen en gesprekken?

Groepen in Signal hebben plaats voor 1.000 mensen, groepsgesprekken voor 75. Groepen in Threema hebben plaats voor 256 mensen, groepsgesprekken voor 16.

Groepen in Session stoppen bij 100 mensen. Bellen en videobellen zijn daar een bètafunctie, die uit staat tot je hem aanzet in de instellingen. De gratis app van Element heeft één-op-één- en groepsgesprekken, met spraak en video.

### Wil je je eigen server draaien?

Element is hier de enige app die daarvoor gemaakt is. Element draait op Matrix, een open standaard waarbij servers met elkaar praten. Je host je eigen server en chat toch met mensen op matrix.org of een andere Matrix-server.

Op de prijspagina van Element staat een gratis Community-editie voor maximaal 100 gebruikers, bedoeld voor niet-professioneel gebruik en om te testen. Organisaties met 100 gebruikers of meer betalen per gebruiker, en die prijs staat niet op de pagina. Een server draaien vraagt technische kennis. Heb je die niet, dan is een gratis account op een bestaande server de makkelijkste start.
